# 坦克大战 · Tank Battle

一个使用原生 **HTML / CSS / JavaScript**（单个文件，无任何依赖）编写的经典《坦克大战》(Battle City) 网页版游戏。

## 🎮 在线试玩

开启 GitHub Pages 后可直接访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

也可以直接双击 `index.html` 在本地浏览器打开。

## 🕹️ 玩法

- 控制我方坦克，**消灭每一关的 20 辆敌方坦克**，同时保护右下角的基地（老鹰）。
- 基地被摧毁，或生命耗尽，游戏即告结束。
- 敌方坦克共 4 种：普通、快速、强力、装甲（需命中 4 次）。
- 摧毁敌人有概率掉落道具：**火力 ★**、**护盾 ⛨**、**生命 ♥**、**炸弹 ✸**。

## ⌨️ 操作

| 按键 | 功能 |
| --- | --- |
| `↑ ↓ ← →` 或 `W A S D` | 移动 |
| `空格` / `J` / `Enter` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 / 取消静音 |

移动端会自动显示虚拟方向键与射击按钮。

## ✨ 特性

- 13×13 网格地图，3 张关卡地图循环，难度随关卡递增
- 砖墙可摧毁、钢墙（火力满级后可摧毁）、水域、树林（遮挡视线）
- 玩家火力升级系统（最多 3 级，满级可击穿钢墙）
- 敌人生成队列、AI 移动与射击
- 计分、生命、关卡进度 HUD
- Web Audio 音效（无需音频文件）
- 响应式布局，支持键盘与触屏

## 🚀 部署到 GitHub Pages

1. 将仓库推送到 GitHub；
2. 进入仓库 **Settings → Pages**；
3. Source 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`；
4. 保存后等待片刻即可通过 Pages 地址访问。
